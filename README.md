# 💰 مَصرفي | Masrofy 📱

> تطبيق جوال (PWA) عربي لتتبع المصاريف والدخل مع تحليلات ذكية — يتثبت على الجوال ويعمل بدون نت.

للمطورين وأدوات البرمجة: اقرأ [AGENTS.md](AGENTS.md) قبل تعديل المشروع؛ يحتوي بنية التطبيق وقواعد سلامة البيانات والاختبار والإصدار.

![PWA](https://img.shields.io/badge/PWA-ready-purple) ![Mobile](https://img.shields.io/badge/Mobile--first-green) ![License](https://img.shields.io/badge/license-MIT-green)

## 📱 التثبيت على الجوال

**أندرويد (كروم):**
1. افتح رابط GitHub Pages على جوالك
2. اضغط ⋮ ← **تثبيت التطبيق / Add to Home screen**
3. بيصير عندك أيقونة مَصرفي مثل أي تطبيق

**آيفون (سفاري):**
1. افتح الرابط في سفاري
2. زر **مشاركة** ← **إضافة إلى الشاشة الرئيسية**

**يعمل بدون نت** بعد أول فتح (Service Worker).

## 📦 نسخة APK (أندرويد)

ملف التثبيت المحلي هو **`Masrofy-v2.0-debug.apk`**، ويُرفع إلى صفحة **Releases** في GitHub (موقّع بمفتاح debug — للاختبار، وليس للنشر في متجر Play).

التثبيت على جوالك:
1. انسخ الملف لجوالك (واتساب / تيليجرام / درايف / USB)
2. افتحه من الجوال ووافق على **التثبيت من مصادر غير معروفة**
3. ثبّت وافتح — بياناتك تُحفظ داخل التطبيق

> بديل بدون APK: ثبّته كـ PWA من المتصفح (الخطوات فوق).

### 🔧 إعادة بناء APK بعد التعديل (للمطورين)

1. عدّل ملفات الويب (`index.html` / `style.css` / `app.js`) كالمعتاد
2. شغّل سكربت البناء على Windows (يتطلب Android SDK، ولا يحتاج Gradle):
```powershell
.\android-src\build-debug.ps1
# الناتج: Masrofy-v2.0-debug.apk
```

`android-src/` هو غلاف WebView خفيف (package: `com.masrofy.app`) ينسخ ملفات الويب أثناء البناء ويعمل محلياً بالكامل.

## 🧠 كيف تشتغل التحليلات الذكية؟

محرك قواعد (Rule-based) في `app.js` دالة `renderInsights()`:
1. يحسب أعلى فئة صرف ونسبتها
2. يحسب متوسط الصرف اليومي ومعدل الادخار
3. يقارن المصروف الشهري بالميزانية
4. يولّد نصائح توفير حسب الفئة الأعلى

تقدر تطورها لاحقاً لاستخدام AI API حقيقي.
