# غلاف Android

غلاف WebView بسيط بلا مكتبات خارجية. يعرض ملفات `assets/www` من أصل HTTPS محلي، يمنع وصول WebView للملفات والمحتوى المحلي، يفتح روابط الويب في المتصفح الخارجي، ويدعم اختيار نسخة JSON وحفظ CSV/JSON عبر منتقي ملفات Android.

ملف `build-debug.ps1` يبني APK تجريبيًا بأدوات Android SDK المحلية ويوقعه بمفتاح Android debug. للنشر، ابنِ نسخة release ووقّعها بمفتاح خاص دائم محفوظ بأمان.
